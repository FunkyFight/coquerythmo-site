## Design Specificity Verdict

**LLM assessment**: Unmistakably authored for this product. The first screen is the Coquerythmo window, the pitch plays as dialogue on a working band ("Et le logiciel, il coûte combien ?" / "Rien. C'est gratuit…" / "Alors je le télécharge."), the download lines are the next lines and park on the red bar, and the hand-drawn lips sync. No other product could reuse this page. The risk is not genericness but runaway specificity: below the window almost every chapter is a full working replica of an app screen (export dialog ~30 controls, node-graph automation editor, server `.env` form, 91-row shortcut table, platform matrix). The first viewport is a pitch; the rest reads like the manual.

## Overall Impression

The first 17 seconds are the best thing on the page. The rest has not been reorganised since the "je me sens overwhelmed" feedback: 18,045 px desktop (17,870 at build review), no collapsible chapter, no `<details>`, 477 focusable elements. Biggest opportunity: progressive disclosure in the band's own grammar, chapters as closed boucles that open on demand, without deleting anything.

## What's Working

1. The story is the demo: the FAQ answer becomes band dialogue and the downloads become its next lines.
2. Band-as-button is genuinely accessible: every canvas line has a real `<a>` twin (version, size, "Build non testée" in the label); focusing a line seeks, pauses and draws a blue frame; reduced motion starts parked on the downloads.
3. Downloads survive failure: GitHub API 403 → identical working links from the snapshot; JS off → full static list in the production build; macOS/Linux shown truthfully as 3.5.1.

## Priority Issues

Fix (reorganise, not delete): each chapter opens collapsed as a "boucle" (strip + lede + one signature demo visible; the rest behind a band-styled `aria-expanded` disclosure "Dérouler la boucle 3 · 3 démos"). Candidates: Anatomie lists/emotions/tables, Projet node graph + "Rien ne se perd", Ensemble `.env` form, Accessibilité 91 shortcuts + matrix, Tutoriels release notes. First read ≈ 7–8 screens. - **[P1] The primary CTA arrives too late.** PARK = 380 frames at 24 fps + 900 ms ≈ 17 s (demo.js:9, hero.js:66); only a 96×24 topbar button before that. Fix: tighten the scene so "Alors je le télécharge." hits the bar by ~6 s, or show the lines waiting at the right edge from frame 0; label the topbar button with the OS. The reading bar also cuts through "Télécharg|er"; park in the gap before the text. Command: /impeccable onboard, /impeccable animate.
- **[P1] The keyboard and screen-reader path fails the core audience.** First hero download at Tab #35 (toolbar = 20 stops); assertive welcome toast at 1.4 s; Ensemble simulation announces assertively on scroll; H2s read with strip prefix ("Jade Tout ce qui défile a un nom."); 41–43 targets under 24 px at 390 px (pj-node__x 16×16, pj-pin 20×20); 4 contrast pairs just under AA. - **[P2] No reassurance at download time; the final choice is duplicated.** 8 targets for 3 OSes; untested quote detached under all 3 columns; nothing about SmartScreen, macOS right-click → Ouvrir, or Ctrl+Maj+N at first launch. Fix: Anatomie → Accessibilité (short) → Ensemble → Détection → Export → Projet (collapsed) → Tutoriels → Télécharger; strip labels either all speakers or all topics. Command: /impeccable layout, /impeccable clarify.
